# 오지 탐험대 홈페이지

연세대학교 빈곤문제국제개발연구원(IPAID) 산하 개발협력 학술모임 오지 탐험대의 홈페이지입니다.

## 파일
- `index.html` — 홈페이지 전체
- `archive.json` — 자료실에 보이는 자료 목록

## 대원이 자료를 올리는 법
자료실 오른쪽 "자료 올리기"에서 제목·학기·분류·파일·대원 코드를 넣고 올리면, 파일이 대표 계정(oji.yonsei@gmail.com) 구글 드라이브의 `오지 탐험대 자료실/학기` 폴더에 저장되고 사이트 목록에 바로 나타납니다.

- 올린 자료 옆의 **수정**(제목·학기·분류)과 **삭제** 버튼도 대원 코드가 있으면 쓸 수 있고, 드라이브에 바로 반영됩니다. 삭제한 파일은 드라이브 휴지통으로 옮겨져 30일 안에 복구할 수 있습니다.
- 사이트 목록에는 드라이브에서 **"링크가 있는 모든 사용자" 공유가 켜진 파일**만 보입니다. 숨기고 싶은 자료는 드라이브에서 공유를 끄거나 파일을 삭제하면 됩니다.
- 새 학기 폴더(예: `2027년 1학기`)는 첫 업로드 때 자동으로 만들어집니다. 사이트의 학기 탭은 `index.html`의 `SEMS`에 추가합니다.

### 업로드 서버 설정 (처음 한 번, 운영진)
1. **oji.yonsei@gmail.com**으로 로그인한 브라우저에서 https://script.google.com 에 들어가 **새 프로젝트**를 만듭니다.
2. 기본 코드를 모두 지우고 이 저장소의 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장합니다. 프로젝트 이름은 "오지 탐험대 자료실 업로드"로 합니다.
3. 왼쪽 **톱니바퀴(프로젝트 설정)** → 아래 **스크립트 속성** → **스크립트 속성 추가**: 속성 `UPLOAD_CODE`, 값은 대원들과 나눌 코드.
4. 오른쪽 위 **배포 → 새 배포** → 유형 선택 톱니에서 **웹 앱** → 실행 계정 **나**, 액세스 권한이 있는 사용자 **모든 사용자** → **배포**.
5. 권한 확인 창이 뜨면 대표 계정을 고르고, "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러 허용합니다. 직접 만든 스크립트라 괜찮습니다.
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 `index.html`의 `UPLOAD_API_URL` 자리에 넣습니다.
- 대원 코드를 바꾸려면 3번의 값만 바꾸면 됩니다. `Code.gs`를 고쳤다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다.

## (선택) 링크로 자료 추가하는 법
1. 파일(보고서 PDF, 사진, 카드뉴스)을 구글 드라이브에 올리고, 공유를 **"링크가 있는 모든 사용자 · 뷰어"**로 바꾼 뒤 링크를 복사합니다.
2. 이 저장소에서 `archive.json`을 열고 연필(Edit) 아이콘을 누릅니다.
3. 아래 형식으로 한 줄(항목)을 추가하고 Commit changes를 누릅니다. 1~2분 뒤 사이트에 반영됩니다.

```json
[
  {
    "title": "2026년 1학기 활동 보고서",
    "semester": "2026-1",
    "kind": "활동 보고서",
    "date": "2026-06-22",
    "url": "https://drive.google.com/file/d/파일ID/view"
  }
]
```

- `semester`: `2026-1`(1학기) 또는 `2026-2`(2학기)
- `kind`: `활동 보고서`, `활동 사진`, `카드뉴스`, `발제 자료`, `기타` 중 하나
- 항목이 여러 개면 `}` 뒤에 쉼표(`,`)를 넣고 이어서 씁니다. 마지막 항목 뒤에는 쉼표를 넣지 않습니다.
- 가장 최근 자료 3개는 홈의 "최신 공지"에 "새 자료"로 자동 표시됩니다.

## 수정했는데 예전 화면이 보일 때
- 저장소의 **Actions** 탭에서 배포(초록 체크)가 끝났는지 확인합니다. 보통 1~2분 걸립니다.
- 브라우저 캐시 때문일 수 있습니다. 강력 새로고침(맥 `Cmd+Shift+R`, 윈도우 `Ctrl+Shift+R`)을 하거나 시크릿 창에서 열어 봅니다.
- 휴대폰은 주소 뒤에 `?v=2`처럼 아무 값을 붙여 열면 새 버전을 불러옵니다.
